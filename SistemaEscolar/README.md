# 📚 Sistema Escolar em Java

Sistema de gerenciamento escolar desenvolvido em Java com foco em prática de lógica de programação, vetores, matrizes, estruturas de repetição e manipulação de dados no terminal.

---

# 🚀 Funcionalidades

✅ Cadastro de alunos
✅ Lançamento de notas
✅ Visualização do boletim
✅ Listagem de alunos aprovados
✅ Listagem de alunos reprovados
✅ Validação de entrada de nomes
✅ Formatação de tabela usando `printf`

---

# 🛠 Tecnologias utilizadas

* Java
* IntelliJ IDEA
* Vetores
* Matrizes
* Loops (`for`, `do while`)
* Condicionais (`if`, `switch`)
* `Scanner`
* `printf`

# 📂 Estrutura do sistema

## Vetor de alunos

```java
String alunosCadastrados[]
```

Responsável por armazenar os nomes dos alunos.

---

## Vetor de disciplinas

```java
String[] disciplinas
```

Responsável por armazenar o nome das disciplinas.

---

## Matriz de notas

```java
double notas[][]
```

Estrutura utilizada para armazenar as notas dos alunos.

### Estrutura lógica da matriz

| Linha | Coluna     |
| ----- | ---------- |
| Aluno | Disciplina |

Exemplo:

```java
notas[1][3]
```

Representa:

* aluno da posição 1
* disciplina da posição 3
